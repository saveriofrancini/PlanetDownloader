# PlanetScope illustration

`planet_constellation.png` is a conceptual illustration of Dove-type spacecraft distributed along one near-polar orbital plane. Spacecraft dimensions, number and orbital distances are illustrative; the figure does not reproduce the operational configuration of the full Planet fleet. The Earth occludes the far section of the orbit.

The physical reference is the 3U Dove family, with an elongated camera bus and deployable solar panels. Simplified spacecraft symbols are used at the scale of the illustration.

References:

- [PlanetScope technical description](https://docs.planet.com/data/imagery/planetscope/)
- [Planet photographs of successive Dove designs](https://www.planet.com/pulse/agile-aerospace/)
